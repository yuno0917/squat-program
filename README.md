# スクワット プログラムメーカー

スクワットのMAXを入れるだけで、スクワット専用の4〜12週間プログラムを作る Web ツールです。公開先は https://yuno-lab.com/squat-program/ です。

- 目的（MAXを伸ばす・脚を太くする・両方）、レベル、週1〜3回、期間、苦手なところ、場所を選べる
- 毎回の重さ、余力、休憩、ウォームアップ、片側のプレート、補助種目を出す
- 最後の週はMAX測定か回数チェック。結果から次のプログラムを作り直せる
- 「やった」のチェックと入力内容は、ブラウザ内だけに保存し、サーバーには送信しない

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・プログラム・決め方と根拠・よくある質問・免責 |
| `tests.html` | ロジックのテスト（ブラウザで開くと結果を表示） |
| `js/sp-data.js` | レベル、目的ごとの段階、種目、ウォームアップなどの設定値 |
| `js/sp-program.js` | プログラム作成のロジック |
| `js/app.js` | フォーム・描画・保存・共有リンク・実施チェック |

根拠の研究は、[スクワット伸び計算機](https://yuno-lab.com/squat-goal/evidence.html)と[ボディメイク メニューメーカー](https://yuno-lab.com/body-menu/evidence.html)の研究まとめにリンクしています。設定を変えたら `tests.html` を開き、テストがすべて通ることを確認してください。
